# Assistente newsletter: informativa privacy
- Uso: applicazione personale, utilizzata solo dal suo proprietario.
- Accesso: solo lettura della casella Gmail dedicata (permesso gmail.readonly). Nessun invio, modifica o cancellazione di email.
- Dati: le email vengono elaborate sul server personale del proprietario per creare riassunti. Il testo può essere elaborato da servizi di intelligenza artificiale a questo solo scopo. I dati non vengono venduti né condivisi per altri fini.
- Revoca: accesso revocabile in qualsiasi momento da myaccount.google.com/permissions.
- Contatti: tramite il profilo GitHub del proprietario.
